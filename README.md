# P.O.U.S. — Proof of Useful Stake

An interactive React proof of concept for exploring Proof of Useful Stake protocol designs. The lab lets researchers swap assignment, audit, consensus, reward, and dispute-resolution strategies and test them across adversarial networks of up to 5,000 simulated nodes.

## Live demo

[Open P.O.U.S. on Vercel](https://proof-of-useful-stake.vercel.app/)

## Features

- Modular strategy stack
- Hidden-overlap and zero-knowledge audit experiments
- Merkle and ZK dispute-resolution views
- Node-level inspection
- Reward-distribution analysis
- Deterministic adversarial validation scenarios
- Black-and-white dark interface

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173/`.

## Validate

```bash
npm test
npm run build
```

## Status

This is a research simulator and protocol-design workbench, not a production blockchain implementation or a cryptographic proof system.
